# 📄 História do HTML

Este projeto é uma página web simples desenvolvida em **HTML puro**, com o objetivo de apresentar a história do HTML, sua importância e evolução ao longo do tempo.

---

## 📌 Sobre o projeto

A página aborda de forma introdutória:

* O que é HTML
* Quem criou o HTML
* Ano de criação
* Principais versões do HTML
* Importância da linguagem
* Imagens ilustrativas (criador, logo e folder)

É um projeto ideal para iniciantes que estão aprendendo a estrutura básica de uma página web.

---

## 🛠️ Tecnologias utilizadas

* HTML5

> Não utiliza CSS nem JavaScript — foco total na estrutura da página.

---

## 📂 Estrutura do projeto

```
📁 projeto-html
│-- index.html
│-- folder html.png
```

---

## 🚀 Como executar

1. Baixe ou clone este repositório:

```
git clone https://github.com/seu-usuario/seu-repositorio.git
```

2. Abra o arquivo `index.html` em qualquer navegador (Google Chrome, Edge, etc).

---

## 🧠 Aprendizados

Com este projeto, é possível praticar:

* Estrutura básica do HTML (`<!DOCTYPE>`, `<html>`, `<head>`, `<body>`)
* Uso de títulos (`<h1>` até `<h2>`)
* Parágrafos (`<p>`)
* Links (`<a>`)
* Listas (`<ul>` e `<li>`)
* Imagens (`<img>`)
* Quebras de linha (`<br>`)

---

## ⚠️ Observações

* Algumas imagens são carregadas via URL externa.
* O arquivo `folder html.png` deve estar na mesma pasta do HTML para funcionar corretamente.
* O código pode ser melhorado com CSS para estilização futura.
