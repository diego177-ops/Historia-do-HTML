História do HTML

O que é HTML?

HTML é uma linguagem de marcação para a criação de conteúdo de uma página Web.
Por ser uma tecnologia utilizada para desenvolver sites.

O que é HTML?

Quem criou?

O HTML foi criado por Tim Berners-Lee, como uma ferramenta que permitia acrescentar alguns elementos nos textos usados por ele
e um grupo de pesquisadores, na publicação dos seus trabalhos em uma época em que a Internet ainda dava seus primeiros passos.



Cridor do HTML

Ano de criação:

O HTML surgiu em 1989, no CERN (Organização Europeia para a Pesquisa Nuclear). A proposta de Tim Berners-Lee
era simples: permitir a troca de informações entre pesquisadores por meio de documentos conectados.

Ano de criação do HTML

Principais versões do HTML

  • O HTML surgiu no início dos anos 1990 com recursos simples para estruturar textos e links.

  • HTML 2.0 (1995), ao longo do tempo, passou por várias atualizações, trouxe padronização e formulários;

  • O HTML 3.0 (1997) adicionou mais recursos como tabelas e melhorias visuais;

  • HTML 4.0 (1999), aprimora os padrões da web com melhor acessibilidade, internacionalização, suporte a folhas de estilo e scripts.

  • XHTML 1.0 (2000), combinando a flexibilidade da linguagem de marcação com regras estritas de sintaxe

  • HTML5 (2014), introduziu suporte moderno a multimídia, semântica e aplicações web.
